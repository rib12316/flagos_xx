## P2 · KV int8 × 自研 triton dequant（V150 最大单项，2-3 天，16K 投影 +40-90%）

- **与 C500 的本质差异：V150 attention 是我们自己的 triton kernel——in-kernel dequant 可自研，零 vendor 依赖**
- 双杠杆：容量（池 588K→~1.17M → 16K 同驻 33→**64**，消除排队——deepdive §4 机理改写版）+
  带宽（16K decode 流量 91% 在 KV 读，字节减半）
- 仓内资产：P2 per-token-per-head KV 量化 scheme + `scripts/d2/phase2_kv_probe.py`
  （旧判决 0.90× 只测了带宽臂且是延迟 bound 口径，**容量臂收益从未计入——需重估**）；
  kernel 工程纪律模板 `vendor/iluvatar/attn_splitkv.py` 头注（裸 jit/禁 atomic/禁运行时 autotune/
  TILE16 物理连续/w1s1/静态查表——V0-V3 真机跑过的全套纪律）
- 设计要点：int8 KV + per-(token,head) 或 per-(token,head,dim/8) scale、in-kernel 乘 scale 进
  QK/PV（抄 FlashMLA 的 scale-紧邻-数据布局避免第二访存流）、写入路径=量化版 reshape_and_cache
- 精度：V150 余量 2.1pp，T0 对拍 + 105 题全量门；回退 env 门
- 与 P1 的组合检查点：P1 落地后 16K 时间构成变化，KV int8 收益需重算
