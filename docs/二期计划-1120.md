4. TD 在沐曦栈不存在（triton 3.0 < 3.3，hop 内 stub 强制 USE_TD=False）→ 天数 TD 收益不可迁移；
5. 融合 int8 GEMM tile 在沐曦被 64KB smem 挡（bedf8ca 判决）；
6. 自研 split-KV kernel（V0-V3 + hop + 单测）在 `feat/d2-w8a8-quant` 分支（已 push）；
