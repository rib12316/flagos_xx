## 2. 环境安装（顺序执行，每步有判据）

### 2.1 权重（约 4.7GB）
原始模型 = HuggingFace `openbmb/MiniCPM5-2B`（LlamaForCausalLM，bf16）。两条路任选：
```bash
# 路 A：ModelScope（国内直连）
pip install modelscope -q && python3 -c "
from modelscope import snapshot_download
snapshot_download('openbmb/MiniCPM5-2B', local_dir='/workspace/MiniCPM5-2B')"
# 路 B：hf-mirror
HF_ENDPOINT=https://hf-mirror.com huggingface-cli download openbmb/MiniCPM5-2B \
  --local-dir /workspace/MiniCPM5-2B
```
判据：`config.json` 的 `architectures==["LlamaForCausalLM"]`、`torch_dtype==bfloat16`、safetensors 全量、总大小 ~4.7G。

### 2.2 Python 依赖（沐曦镜像应已含大件）
核对（非破坏性）：`torch==2.8.0+metax3.7.0.7`、`triton==3.0.0+metax3.7.0.7`、`vllm==0.24.0+empty`、
`flash_attn==2.6.3+metax*`、`mctlassEx`（`import torch; import mctlassEx` 必须成功）、`flag_gems==5.3.5`。
**缺 mctlassEx / torch 版本不符 → 停，报任务板 blocked**（不要自行 pip 装网络版 torch/vllm——会破坏镜像栈）。
evalscope 精度 1.11.x、datasets 等按需再装。

### 2.3 本仓插件 + provenance 四查
```bash
pip install --no-deps --no-build-isolation ./vllm-plugin-FL
# 四查：
pip show vllm-plugin-fl | grep -i location          # ① 指向本机 site-packages
cat <site-packages>/vllm_plugin_fl-0.0.0.dist-info/direct_url.json   # ② 指向本仓克隆
diff -rq <site-packages>/vllm_fl ./vllm-plugin-FL/vllm_fl            # ③ 一致
pip show flag_gems | grep Version                    # ④ 5.3.5
```

### 2.4 w8a8 量化 ckpt 幂等再生（DELIVERY.md 命令逐字）
act_stats 已随仓库克隆（`results/20261107_d2_actstats/act_stats.json`）：
```bash
python3 vllm-plugin-FL/tools/quantize_int8_rtn.py \
    --src /workspace/MiniCPM5-2B \
    --dst /workspace/MiniCPM5-2B-w8a8-v2 \
    --smooth-alpha 0.5 \
    --act-stats results/20261107_d2_actstats/act_stats.json \
    --lm-head-int8 --seed 1234
```
判据：`295 tensors packed` RESULT 行 + ckpt 目录 ~2.7G + config 含 `quantization_config`。

### 2.5 一键审计 + 烟测
```bash
bash scripts/d5/env_audit_metax.sh        # 必须 AUDIT_GREEN

  --served-model-name minicpm --gpu-memory-utilization 0.85 --max-model-len 131072 \

```

### 2.6 与 A 机交叉验证（±2% 带内才算环境合格）
